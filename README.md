# Polite Scraper

A Polite web scraper for the Books to Scrape sandbox site.

---

## Target Classification

- **Site :** Books to Scrape (https://books.toscrape.com/)
- **Purpose :** Practice for learning web scraping
- **Scope :** First 3 catalogue pages only. These pages contain 60 books in total.
- **Data :** Title, product URL, price, availability, rating, description,
  source catalogue page, and fetch timestamp
- **Robots.txt:** no robots file found
- **Ethics:** I will not reuse this code on another site without checking its rules and terms first.
